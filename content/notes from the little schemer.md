s-expressions or scheme expressions is a [[construct]]. everything in scheme is an atom. 

anything inside parenthesis is a list. 

for example: 

``` lisp
(a b c) -> a list of a, b, c. 

atom -> is an atom. 

calling 'atom will output the result of atom. 
```
